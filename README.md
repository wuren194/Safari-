## 📦 更新脚本到 GitHub

每次修改完脚本后，在终端运行：

```bash
cd ~/Desktop/工具/脚本 && git add . && git commit -m "update" && git push
```

或者分步执行：

```bash
cd ~/Desktop/工具/脚本
git add .
git commit -m "描述你改了什么"
git push
```

---

## 🔄 Tampermonkey 自动更新

脚本已配置自动更新，Tampermonkey 会定期检查 GitHub 上的最新版本。

**首次安装脚本：**
1. 打开 raw 链接：`https://raw.githubusercontent.com/wuren194/Safari-/main/mens1069优化.user.js`
2. Tampermonkey 会弹出安装提示，点击安装

**手动检查更新：**
1. 打开 Tampermonkey 面板
2. 进入对应脚本的设置
3. 点击 "检查更新"
